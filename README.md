# Трекер учебных задач

Веб-сервис для управления курсами, заданиями, дедлайнами и статусами.
Разрабатывается как командный проект по курсу «Методы оптимизации в разработке программных решений».

## О проекте

Сервис помогает студенту вести все учебные задачи в одном месте: создавать курсы, добавлять задания с дедлайнами, отслеживать статус выполнения и видеть ближайшие сроки на главной странице.

## Стек

| Слой | Технология |
|---|---|
| Язык | Python 3.11 |
| Бэкенд | FastAPI |
| Шаблоны | Jinja2 |
| CSS | Bootstrap 5 |
| БД | SQLite |
| API-документация | Swagger (автогенерация FastAPI) |
| Контейнеризация | Docker + docker-compose |
| CI/CD | GitHub Actions |
| Трекер задач | GitHub Issues + Projects |

## Запуск

Сервис ещё не реализован. Код появится в ЛР2, запуск через Docker — в ЛР2 / ЛР3.

Планируемая команда запуска:

```bash
docker compose up
```

Планируемые адреса после реализации:

- Веб-интерфейс: http://localhost:8000
- Swagger-документация: http://localhost:8000/docs
