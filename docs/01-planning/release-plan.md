# План релиза MVP

## Сетевой график

Зависимости между историями MVP:

    US-2 (Создание курса)
      ├──► US-3 (Список курсов) ──┐
      └──► US-5 (Создание задания)│
              └──► US-6 (Список заданий) ──┬──► US-1 (Главная)
                                           │
                                           └──► US-9 (Ближайшие дедлайны)

Длительности взяты из ожидаемых значений PERT (E, ч):

| История | E (ч) | Предшественники |
|---|---|---|
| US-2 | 2.17 | — |
| US-3 | 2.00 | US-2 |
| US-5 | 5.50 | US-2 |
| US-6 | 3.33 | US-5 |
| US-1 | 4.33 | US-3, US-6 |
| US-9 | 4.17 | US-6 |

## Критический путь

Критический путь: US-2 → US-5 → US-6 → US-1.

Суммарная длительность: 2.17 + 5.50 + 3.33 + 4.33 = 15.33 ч.

Резервы:

| История | Резерв (ч) |
|---|---|
| US-3 | 15.33 − (2.17 + 2.00 + 4.33) = 6.83 |
| US-9 | 15.33 − (2.17 + 5.50 + 4.17) = 3.49 |

## Вероятность завершения к дате защиты ЛР3

Суммарное стандартное отклонение критического пути:

    σ = √(0.50² + 1.17² + 0.67² + 1.00²) ≈ 1.71 ч

Если на реализацию MVP отведено 20 ч:

    Z = (20 − 15.33) / 1.71 ≈ 2.73
    P ≈ 0.997

Вероятность завершения MVP к дате защиты ЛР3 составляет около 99.7%.

| Вероятность | Срок завершения MVP |

| 50% | 2.5 недели |
